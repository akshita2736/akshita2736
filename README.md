## 🚀 Featured Projects

### 🛡️ RAG-Shield — Reliability Framework for RAG Systems

**Python | FAISS | SentenceTransformers | Groq | Streamlit**

A reliability framework designed to detect prompt injection and improve the reliability of Retrieval-Augmented Generation systems.

- Developed a three-layer detection framework combining rule-based scanning, an embedding-based classifier, and LLM review.
- Built an adversarial benchmark with direct, obfuscated, and paraphrased attacks alongside challenging benign examples.
- Evaluated detection performance across different attack types.

**Results:** 98.4% F1-score | 1.1% False Positive Rate

[Live Demo](https://rag-shield.streamlit.app/) · [View Repository](https://github.com/akshita2736/rag-shield)

### 🩺 Women's Hypothyroidism Detection & Screening

**Python | Scikit-learn | FastAPI | Groq | React | Tailwind CSS**

A machine learning research project on early hypothyroidism detection among women, extended into a full-stack screening application.

- Preprocessed and engineered features from the UCI Thyroid Disease dataset and benchmarked five machine learning classifiers.
- Co-authored and presented the research at the **7th International IEEE Conference on AI and Speech Technology (AIST 2025)**.
- Achieved 96.8% accuracy and 97.1% recall using Random Forest.
- Extended the research model into a web application supporting manual input and PDF laboratory report uploads.
- Built a FastAPI backend for ML inference and Groq-powered clinical summaries, with automated hormone-value extraction using pdfplumber.

[Live Demo](https://hypothyroid-screening.vercel.app/) · [View Research](https://ieeexplore.ieee.org/document/11441503)
